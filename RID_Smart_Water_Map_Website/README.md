# RID Smart Water Map

เว็บไซต์ต้นแบบสำหรับติดตามสถานการณ์น้ำ ค้นหาพื้นที่ชลประทาน และทดลองแจ้งเหตุ

## เปิดใช้งาน

เปิด `index.html` ด้วยเบราว์เซอร์ หรือรันเว็บเซิร์ฟเวอร์จากโฟลเดอร์โครงการ

```sh
python3 -m http.server 8080
```

จากนั้นเปิด `http://localhost:8080` ภาพดาวเทียมและแผนที่ถนนใช้การเชื่อมต่ออินเทอร์เน็ต

| ไฟล์ | หน้าที่ |
| --- | --- |
| `index.html` | โครงหน้าเว็บ เมนู และฟอร์ม |
| `css/styles.css` | รูปแบบเว็บไซต์ |
| `js/app.js` | การค้นหาแผนที่ การแจ้งเหตุ และการติดตามสถานะ |
| `js/water-data.js` | ชุดข้อมูลสถานการณ์น้ำสำหรับทดสอบ |
| `js/administrative-areas.js` | ชุดข้อมูลจังหวัด อำเภอ เขต ตำบล และแขวง |
| `js/translations.js`, `js/charts.js` | ข้อความภาษาไทยและอังกฤษ และกราฟ |
| `css/leaflet.css`, `js/leaflet.js` | Leaflet พร้อมสัญญาอนุญาตในไฟล์ JavaScript |

สามารถนำไฟล์ทั้งหมดในโฟลเดอร์นี้ ไปวางที่โฟลเดอร์รากของเว็บโฮสติ้งแบบ Static ได้

ข้อมูลน้ำและการเข้าสู่ระบบอยู่ในโหมดทดสอบ เรื่องร้องเรียนที่ทดลองแจ้งจะเก็บในเบราว์เซอร์เครื่องนั้น
